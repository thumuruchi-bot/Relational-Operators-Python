# Relational Operators (Python)

## Description
A simple Python program demonstrating relational operators.

## Features
- Equal To (==)
- Not Equal To (!=)
- Greater Than (>)
- Less Than (<)
- Greater Than or Equal To (>=)
- Less Than or Equal To (<=)

## Technology Used
- Python

## Output
a == b : False
a != b : True
a > b : True
a < b : False
